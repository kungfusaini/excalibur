# EXCALIBUR

Repo for my custom guitar build EXCALIBUR

The goal is to integrate my [Fishman Tripleplay](https://fishman.com/tripleplay/) with my [MidiPlus miniEnginePro](https://www.midiplus.com.tw/en/product-detail/miniEnginePro/)

I need a rasbery pi interface between the two because the miniEngine has a very poor user experience but has great sounds, and the Fishman is a bit opeque with it's operations.
The goal is to capture the tripleplay output perform some processing and send it to the MidiPlus.
